This is the repository of my personal [webpage](https://annalindeberg.github.io/). Currently being hacked together bit by bit...

## Run locally

Install the Ruby version listed in `.ruby-version`. From the repository directory, run `bundle install` once, then `bundle exec jekyll serve`. Open <http://127.0.0.1:4000/> to preview the site; press Ctrl+C to stop the server.
